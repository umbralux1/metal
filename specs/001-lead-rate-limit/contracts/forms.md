# Контракт форм (Contracts): Ограничение частоты заявок

Адреса и поля форм не меняются. Меняется только ответ на заявку сверх порога.

## `POST /api/lead/` — заявка с карточки товара

| Случай | Код | Ответ |
|---|---|---|
| Принята (как сейчас) | 200 | `leads/_done.html` (fetch) или `leads/done_page.html` |
| Ошибка в форме (как сейчас) | 422 / 404 | `leads/_form.html` с ошибкой; в счёт не идёт |
| Ловушка для ботов (как сейчас) | 200 | `leads/_done.html` без номера; в счёт не идёт |
| **Сверх порога** | **429** | `leads/_form.html`: ошибка «Слишком много заявок. Попробуйте через несколько минут или позвоните: <телефон>», введённые имя, телефон, комментарий и параметры расчёта в полях. Заявка не сохранена, менеджер не уведомлён |

## `POST /cart/checkout/` — заказ из корзины

| Случай | Код | Ответ |
|---|---|---|
| Принят (как сейчас) | 200 | `cart/done.html`, корзина очищена |
| Ошибка в форме (как сейчас) | 422 | `cart/page.html` с ошибкой; в счёт не идёт |
| Ловушка / пустая корзина (как сейчас) | 303 | на `/cart/`; в счёт не идёт |
| **Сверх порога** | **429** | `cart/page.html` с той же ошибкой; корзина не очищается, введённые данные заказа в полях. Заказ не сохранён |

Порог общий для обеих форм (FR-001).
