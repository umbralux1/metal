# План реализации (Implementation Plan): Ограничение частоты заявок

**Ветка (Branch)**: `001-lead-rate-limit` | **Дата (Date)**: 2026-10-27 | **Спецификация (Spec)**: [spec.md](spec.md)

**Вход (Input)**: спецификация `specs/001-lead-rate-limit/spec.md`

## Кратко (Summary)

С одного адреса подключения — не больше 5 заявок за 10 минут, заявки с карточки и заказы из корзины вместе.
Счёт ведётся по таблице заявок: у заявки сохраняется отпечаток адреса (HMAC с `SECRET_KEY`), проверка — число заявок
с тем же отпечатком за окно по часам базы. Проверка и сохранение — в одной транзакции под блокировкой по отпечатку,
поэтому счёт общий для всех копий сайта, переживает перезапуск и не пропускает одновременные заявки.
Сверх порога — код 429 и форма с сообщением и телефоном, введённое остаётся.

## Технический контекст (Technical Context)

**Язык и версия (Language/Version)**: Python 3.11

**Основные зависимости (Primary Dependencies)**: FastAPI, Jinja2, SQLAlchemy async, Alembic. Новых нет: HMAC —
стандартная библиотека, блокировка — `pg_advisory_xact_lock` PostgreSQL.

**Хранение (Storage)**: PostgreSQL, поле `leads.client_hash` и индекс (data-model.md)

**Тесты (Testing)**: pytest + httpx (ASGI). Браузерные тесты не нужны: обработчик формы на карточке заменяет её
ответом при любом коде (research.md, п. 6).

**Платформа (Target Platform)**: Linux; разработка — Render, рабочий сайт — российский дата-центр (Yandex Cloud или
Selectel); одна или несколько копий сайта

**Тип проекта (Project Type)**: веб-сайт с серверным рендерингом и админкой

**Затронутые модули (Modules)**: `app/leads` (основное), `app/cart` (обработчик заказа), `app/core` (настройки,
адрес подключения), `app/admin` (вход берёт адрес из ядра)

**Ограничения (Constraints)**: +2 запроса к базе на принятую заявку (блокировка и счёт) — по индексу, незаметно.
Адреса и поля форм не меняются.

**Решение по структуре (Structure Decision)**: порог — правило заявок, поэтому живёт в сервисе заявок и срабатывает
внутри `create_lead`: обе формы проходят через неё, обойти порог новой формой нельзя. Отпечаток — чистая функция,
чтобы проверить FR-010 без базы. Адрес подключения нужен трём модулям — в ядро.

**Существующие тесты**: они отправляют десятки заявок с одного адреса в общей тестовой базе и упрутся в порог.
Фикстура в `conftest.py` поднимает порог для всех тестов, кроме `tests/test_lead_limit.py`, где порог настоящий
и у каждого теста свой адрес подключения.
