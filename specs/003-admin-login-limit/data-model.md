# Модель данных (Data Model): Ограничение входа в админку

## Таблица `admin_login_failures`

Одна строка — одна неудачная попытка входа в админку. Живёт не дольше окна (15 минут).

| Колонка | Тип | Что значит |
|---|---|---|
| `id` | целое, ключ | Номер строки |
| `client_hash` | строка 32, не пусто | Отпечаток адреса подключения (`client_fingerprint`, как у заявок); сам адрес не храним (FR-008) |
| `created_at` | дата и время с поясом, не пусто, `now()` базы | Когда была попытка; окно считается по часам базы |

Логин и пароль не хранятся (FR-008). `updated_at` не нужен — строки не меняются.

**Индексы**: `(client_hash, created_at)` — счёт попыток адреса; `(created_at)` — удаление старых.

**Модель**: `AdminLoginFailure` в `app/admin/models.py`, регистрируется в `app/models.py`.

## Правила

- Попытка с закрытого адреса (≥ порога записей за окно) — новой записи нет (FR-002).
- Неверный логин или пароль с открытого адреса — новая запись.
- Удачный вход — все записи адреса удаляются (FR-004).
- Каждая попытка — удаляются записи всех адресов старше окна (FR-009).
