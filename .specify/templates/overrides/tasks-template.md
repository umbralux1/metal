# Задачи (Tasks): [FEATURE NAME]

**Вход (Input)**: документы из `specs/[###-feature-name]/`

- В описании — точные пути файлов и номера требований (`FR-###`)

## Зависимости и порядок

- Фаза 1 → **СТОП** → Фаза 2 → сценарии по приоритету (P1 → P2 → …) → Фаза N.
- Внутри сценария: типы и чистые функции → сервис → обработчик и шаблон.
- Задачи с [P] в одной фазе можно делать в любом порядке.
- Коммит один на фичу, делает владелец после Фазы N.
