# Ошибки и регрессионные тесты

Журнал найденных ошибок. У каждой — номер `BUG-NNN` и регрессионный тест с этим номером в описании
(`"""BUG-001: …"""`): `grep -rn BUG-001` находит и запись, и тест. Тест не удаляют и не ослабляют — он не даёт
ошибке вернуться. Порядок работы — в `CLAUDE.md`, раздел «Ошибки».

Статусы: **открыта** → **в работе** (тест написан и падает) → **исправлена** (коммит сделан).

Шаблон записи:

```
## BUG-NNN: коротко, что не так
- **Статус:** открыта
- **Найдена:** дата, кем или чем (владелец на сайте, mypy, тест)
- **Что видно:** что делал и что получил вместо ожидаемого
- **Как воспроизвести:** браузер и ширина окна, адрес, действия по шагам
- **Причина:** — (после разбора)
- **Исправление:** — (коммит `fix: … (BUG-NNN)`)
- **Регрессионный тест:** — (файл::тест)
```

## BUG-004: клик по строке в таблице товаров всегда открывает последний товар
- **Статус:** открыта
- **Найдена:** 23.10.2026, владелец на локальном сайте
- **Что видно:** в результатах поиска «Арматура 12» клик в любое место строки «Арматура 12 мм А1»
  или «Арматура 12 мм А400» открывает «Арматура 12 мм А500С» — последнюю строку. Другие товары не открыть.
  Та же таблица — на страницах разделов каталога.
- **Как воспроизвести:** http://127.0.0.1:8000/search/?q=Арматура+12, кликнуть по строке А400
  (не по названию, например по цене). Браузер владельца — уточняется. В Chromium (встроенный браузер)
  не воспроизводится.
- **Причина (предварительно):** строка кликается целиком за счёт растянутой ссылки
  (`.p-name a::after { position: absolute; inset: 0 }`), граница растяжения — `tr { position: relative }`.
  Браузер, который не считает строку таблицы такой границей, растягивает слой каждой ссылки на всю таблицу,
  сверху оказывается слой последней.
- **Исправление:** —
- **Регрессионный тест:** —

## BUG-003: файл вместо текста в форме заявки — ошибка 500
- **Статус:** исправлена
- **Найдена:** 22.10.2026, mypy (`app/leads/router.py` в исключениях)
- **Что видно:** POST `/api/lead/` с файлом в поле `qty` — ошибка 500 вместо отказа.
- **Причина:** значения формы передавались в калькулятор без проверки, что это строки.
- **Исправление:** `fc84946 fix: product page without drawing sizes, file in lead form` — отказ 422.
- **Регрессионный тест:** `tests/test_calc_api.py::test_lead_with_file_instead_of_text_is_rejected`

## BUG-002: страница товара падает, если чертёж задан вручную, а размера нет
- **Статус:** исправлена
- **Найдена:** 22.10.2026, mypy (`app/catalog/drawings.py` в исключениях)
- **Что видно:** в «Доп. свойствах» товара `{"profile": "tube_rect"}`, толщина стенки не заполнена — страница
  товара отдаёт 500.
- **Причина:** чертёж рисовался из пустых размеров (`float(None)`).
- **Исправление:** `fc84946 fix: product page without drawing sizes, file in lead form` — без размеров
  чертёж не рисуется.
- **Регрессионный тест:** `tests/test_drawings.py` (все тесты файла)

## BUG-001: время в админке на 3 часа меньше московского
- **Статус:** исправлена
- **Найдена:** 22.10.2026, владелец — заказ в 21:58 показан в админке как 18:58
- **Причина:** база отдаёт время в UTC, админка показывала его без перевода в часовой пояс сайта.
- **Исправление:** `f445813 fix: show admin times in site timezone` — настройка `TIMEZONE`, по умолчанию Москва.
- **Регрессионный тест:** `tests/test_admin_time.py` (все тесты файла)
