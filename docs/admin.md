# Админка

Управление каталогом, ценами, SEO-страницами и заявками. Работает на SQLAdmin (`app/admin/`).

## Вход

| Где | Адрес |
|---|---|
| Локально (запущен `python main.py`) | http://127.0.0.1:8000/admin |
| Render | `https://<сервис>.onrender.com/admin` |

Логин и пароль — `ADMIN_USERNAME` и `ADMIN_PASSWORD`: локально в `.env`, на Render в `deploy/render.env`.

- Ссылки на админку на сайте нет специально. `/admin/` закрыт в `robots.txt`.
- Пароль не задан — админки нет совсем, по адресу будет «Not Found».
- 5 неверных паролей за 15 минут — вход с этого IP закрывается на 15 минут.
- Сессию подписывает `SECRET_KEY`. Если он не задан, после перезапуска сервера придётся войти заново.

Кнопки SQLAdmin на английском (Save, Delete, Actions), подписи полей и разделов по-русски.

## Меню

| Группа | Раздел | Для чего |
|---|---|---|
| Каталог | Разделы | Дерево каталога: «Арматура → А500С» |
| Каталог | Товары | Карточки товаров с ценами |
| Каталог | Цены | Все цены одним списком (обычно не нужен: цены правятся в товаре) |
| Каталог | Посадочные (SEO-фильтры) | Страницы «Арматура 12 мм», «Труба профильная 40х40» |
| SEO | Редиректы | Перенаправления со старых адресов |
| Продажи | Заявки | Заявки с карточек и заказы из корзины |
| Доставка | Машины | Машины доставки и тарифы: грузоподъёмность, длина кузова, цены |

Устройство таблиц, которые стоят за разделами, описано в [database.md](database.md).

## Главное правило: ничего не удалять

Разделы и товары удалить нельзя, кнопки Delete у них нет. Чтобы убрать позицию с сайта, снимите **«Активен»**.
Страница исчезнет, а её адрес начнёт перенаправлять (301) на раздел выше. Так ссылки, которые уже есть в поиске
Яндекса и Google, не превращаются в ошибку 404. Чтобы вернуть позицию, поставьте галочку обратно.

**Выключенный раздел прячет всё, что внутри:** подразделы, товары и страницы размеров пропадают с сайта, из меню,
sitemap и поиска, их адреса перенаправляют на ближайший видимый раздел выше или в каталог. Сами подразделы
и товары не меняются — в админке у них по-прежнему стоит «Активен». Включили раздел — вернулось всё сразу.

**Скрыты на запуске** (22.10.2026, вернуть позже): Штакетник металлический, Заборы, Крепёж, Фитинги стальные,
Стройматериалы, Петли, Профнастил, Заглушки для профильных труб. Чтобы вернуть раздел — **Каталог → Разделы**,
откройте его и поставьте «Активен».

## Товары

**Каталог → Товары.** В списке видны название, раздел, цены, наличие и активность. Поиск — по названию,
артикулу и адресу.

### Добавить товар

1. **+ New Product**.
2. Заполните поля (обязательны только название и раздел):

| Поле | Как заполнять |
|---|---|
| Название | Как в прайсе: «Арматура 12 мм А500С», «Труба профильная 40х20х2» |
| Slug | Оставьте пустым — соберётся из названия латиницей |
| Раздел | Начните печатать название, выберите из списка. Выбирайте самый точный подраздел |
| Артикул | Необязательно. Должен быть уникальным |
| Марка стали / класс | `Ст3сп`, `А500С`, `09Г2С` |
| ГОСТ / ТУ | `ГОСТ 34028-2016` |
| Диаметр / Ширина / Высота / Толщина, мм | Только те, что есть у этого проката (см. таблицу ниже) |
| Длина прутка / трубы, м | Нужна калькулятору: по ней он считает целые прутки и резку |
| Вес 1 м, кг | Нужен для пересчёта метров в тонны и для цены за тонну |
| Вес 1 шт., кг | Для штучных товаров — лист, свая, профнастил. По нему подбирается машина доставки |
| Длина 1 шт., м | Самая длинная сторона одной штуки: лист 1250×2500 — `2.5`. Тоже для подбора машины |
| Основная единица продажи | Метр, тонна, штука или м². В ней показывается цена «от» и итог калькулятора |
| **Цены** | В рублях, см. ниже |
| В наличии | Снимите, если товара временно нет. Страница останется |
| Активен | Снимите, чтобы убрать товар с сайта |
| Доп. свойства (JSON) | Обычно `{}`. `{"profile": "angle"}` — какой чертёж сечения рисовать |
| H1, Title, Description, SEO-текст | Оставьте пустыми — соберутся по шаблону с ценой |

3. **Save**.

Какие размеры заполнять:

| Прокат | Поля |
|---|---|
| Арматура, круг, катанка | Диаметр |
| Труба круглая, свая | Диаметр, Толщина (стенка) |
| Труба профильная | Ширина, Высота, Толщина (стенка) |
| Уголок | Ширина, Высота (полки), Толщина |
| Полоса | Ширина, Толщина |
| Квадрат | Ширина |
| Лист | Толщина |

Для доставки сайту нужно знать вес и длину заказа. У прутков и труб они берутся из «Вес 1 м» и «Длина прутка»,
у штучных товаров — из «Вес 1 шт.» и «Длина 1 шт.». Не заполнено — машину для такого заказа подтвердит менеджер.

Размеры важны не только для карточки: по ним товар попадает на страницу своего размера
(«Арматура 12 мм») и в адрес вида `/catalog/armatura/12-mm/12-mm-a500s/`.

### Цены

В форме товара четыре поля: **за метр, за тонну, за штуку, за м²**. Вводите в рублях:

- `43,25`, `43.25` или `48 700` — всё подойдёт;
- не больше двух знаков после запятой;
- пустое поле — такой цены у товара нет (если цена была, она удалится).

Обычно у металлопроката две цены — за метр и за тонну. Цена за тонну включается в калькуляторе
от 1 тонны (настройка `TON_PRICE_FROM_KG`). Сваи продаются штуками, лист — м² или штуками.

### Что происходит при сохранении

- Собирается адрес из раздела и slug. Если такой адрес уже занят, админка покажет ошибку.
- Поменяли название, slug или раздел — со старого адреса ставится 301 на новый.
- Обновляется текст для поиска по сайту.
- Запускается генератор посадочных: новый размер получает свою страницу, товар переезжает внутрь неё.
- Меню каталога на сайте обновляется в течение минуты.

## Разделы

**Каталог → Разделы.** Дерево каталога. Корневые разделы (без родителя) показываются в меню «Каталог»
на сайте, значок подбирается по адресу (`armatura`, `truba`, `list`…).

| Поле | Как заполнять |
|---|---|
| Название | «Квадратная» |
| Slug | Пусто — из названия |
| Родитель | Раздел выше. Пусто — корневой раздел |
| Порядок | Чем меньше число, тем выше в меню |
| Активен | Снимите, чтобы скрыть раздел. Адрес будет перенаправлять на раздел выше |
| H1, Title, Description, SEO-текст | Пусто — по шаблону |

Если поменять slug или родителя, у раздела, всех подразделов, посадочных и товаров внутри поменяются адреса.
Со всех старых адресов админка сама поставит 301. Вложить раздел в самого себя нельзя.

## Посадочные (SEO-фильтры)

**Каталог → Посадочные.** Страницы под поисковые запросы с размером: «арматура 12 мм»,
«труба профильная 40х40». Посадочная показывает все товары раздела с этим размером: разные марки,
толщины стенки.

Колонки списка:

- **Авто** — страницу создал генератор, он же её обновляет.
- **В индексе** — страница открыта для поисковиков. Если на неё попало меньше 2 товаров, генератор снимает
  галочку: страница с одним товаром дублирует карточку этого товара.

### Генератор

Создавать посадочные руками обычно не нужно. Генератор смотрит, какие размеры есть в товарах, и сам создаёт
и обновляет страницы. Он запускается:

- при сохранении товара, раздела или посадочной;
- вручную: отметьте любую посадочную галочкой → **Actions → «Обновить посадочные из каталога»**;
- из консоли: `python -m app.catalog.landings`.

Для каких разделов и по каким размерам делаются страницы, задано в `app/catalog/landing_rules.py`.

### Правка вручную

Можно поправить название, H1, title, description и SEO-текст. После правки посадочная становится **ручной**
(«Авто» гаснет), и генератор её больше не трогает. В title и description можно написать `{price}` — подставится
минимальная цена: «от 43,25 ₽».

Поле **Фильтр** — JSON с условием отбора товаров:

```json
{"diameter_mm": 12}
{"width_mm": 40, "height_mm": 40}
{"diameter_mm": [10, 12]}
```

Список значений означает «любое из». Допустимые ключи перечислены в подсказке под полем.

Удалённая посадочная перенаправляет в свой раздел. Если её размер всё ещё есть в товарах, генератор создаст
её снова — чтобы этого не было, лучше снять «В индексе», а не удалять.

## Редиректы

**SEO → Редиректы.** Список перенаправлений «откуда → куда». Почти все записи появляются сами при смене адресов.

Добавить свой — например, когда переносите сайт и у старых страниц были другие адреса:

| Поле | Пример |
|---|---|
| Откуда | `/catalog/old-armatura/` — без домена |
| Куда | `/catalog/armatura/` |
| Код | `301` — переехало навсегда (почти всегда нужен он), `302` — временно |

Слеш в конце и в начале добавится сам, «откуда» приводится к нижнему регистру.

## Заявки

**Продажи → Заявки.** Сюда попадают:

- **заявка с карточки товара** — товар, количество и сумма из калькулятора;
- **заказ из корзины** — в колонке «Товар» написано «Корзина: N поз.».

В списке видны номер, время, товар, имя, телефон, сумма и статус. Новые сверху. Поиск — по телефону,
имени и товару.

Откройте заявку (значок глаза), чтобы увидеть всё. У заказа из корзины — таблица позиций со ссылками на товары,
количеством, резкой и суммой, а под ней:

- **получение** — самовывоз или доставка: адрес, машина, километры и цена доставки. «Стоимость уточнит менеджер» —
  покупатель дальше 200 км; «машину и рейсы подобрать менеджеру» — заказ тяжелее любой машины;
- **покупатель** — частное лицо или организация с названием и ИНН;
- **оплата** — при получении или по счёту;
- **товары · доставка · итого**. «Сумма» в списке заявок — итог вместе с доставкой.

Сумма в заявке зафиксирована на момент оформления: если потом поменять цены, заявка не изменится.

В заявке можно менять только **статус** и **комментарий** (карандаш):

| Статус | Когда ставить |
|---|---|
| Новая | Так приходит заявка |
| В работе | Позвонили, обсуждаете |
| Выполнена | Отгрузили |
| Спам | Бот или ошибочная заявка |

Создать заявку в админке нельзя — только с сайта.

## Машины доставки

**Доставка → Машины.** Какие машины возят заказы и сколько стоит доставка. По грузоподъёмности и длине
кузова сайт решает, какие машины подходят под заказ; по тарифу считает цену. Подробно — [delivery.md](delivery.md).

В списке машины идут по полю «Порядок» — так же, как карточки при оформлении заказа.

| Поле | Как заполнять |
|---|---|
| Название | Так его увидит покупатель: «Грузовик до 5 т». Два одинаковых названия нельзя |
| Грузоподъёмность, кг | Целое число больше 0. Тяжелее машина не повезёт |
| Длина груза, м | Самый длинный груз, который влезает в кузов: `6`, `13,5`. Прутки 11,7 м — только длинномер |
| Базовая цена, ₽ | Цена поездки за первые километры: `1 850` или `1 850,50` |
| Включено, км | Сколько километров входит в базовую цену. 0 — доплата с первого километра |
| Цена за км сверх включённых, ₽ | Доплата за каждый следующий километр. `0` — без доплаты, фиксированная цена |
| Выгрузка силами покупателя | Водитель только привозит. У манипулятора снять: у него кран |
| Порядок | Меньше — выше. Шаг 10, чтобы новую машину можно было вставить между (`25`) |
| Активна | Снимите, чтобы не предлагать машину покупателям |

Цена доставки: базовая + (км − включённые км) × цена за км, если километров больше включённых.
Пример: грузовик до 5 т на 18 км — 2 400 + (18 − 10) × 150 = 3 600 ₽.

Удалить машину нельзя: на неё будут ссылаться заказы. Чтобы убрать её, снимите «Активна».

## Цены (отдельный раздел)

**Каталог → Цены** — все цены всех товаров одним списком. Удобно посмотреть, но править проще в карточке
товара. Здесь цена вводится **в копейках**: `4325` = 43,25 ₽.

## Если что-то не так

| Что видно | Причина и что делать |
|---|---|
| `/admin` — «Not Found» | Не задан `ADMIN_PASSWORD`. Проверьте `.env` и перезапустите сервер |
| Пароль верный, но не пускает | 5 неудачных попыток — подождите 15 минут или перезапустите сервер |
| «Адрес … уже занят другой страницей» | Такой slug уже есть в этом разделе. Поменяйте slug или название |
| «Цена …: введите число» | В поле цены буквы или лишние символы. Пример: `43,25` |
| «Машина «…» уже есть» | Машина с таким названием уже заведена — найдите её в списке или назовите иначе |
| Товар сохранён, а на сайте его нет | Проверьте «Активен» у товара, его раздела и всех разделов выше |
| Новый товар не попал на страницу размера | Заполните размеры (диаметр, ширина…). Страница размера открывается для поиска от 2 товаров |
| Изменения в меню не видны | Меню обновляется раз в минуту — обновите страницу чуть позже |
